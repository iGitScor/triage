# Ready-to-import policy files

Remora's managed settings, as files for each management tool. Generated by `scripts/make-policy-files.py` from one
list of keys: edit the script, not these files. What each key does: [Managing the policy](https://triage.iscor.me/docs/admin/mdm)
([en français](https://triage.iscor.me/docs/fr/admin/mdm)). Each release also attaches them as
`Remora-policy-files.zip`.

| File | For | Holds |
|---|---|---|
| `Remora.mobileconfig` | macOS: Jamf, Kandji, Intune, Mosyle, Apple Business Essentials | The example policy: GitHub, GitLab and Linear, no external AI, avatars. Replace the identifiers and UUIDs with your own |
| `Remora.jamf.json` | Jamf Pro: *Application & Custom Settings* → *External Applications*, domain `fr.igitscor.remora` | Every key, as a form |
| `Remora.admx`, `en-US/Remora.adml`, `fr-FR/Remora.adml` | Windows: Group Policy (`PolicyDefinitions` or the central store), Intune's imported administrative templates | Every key, under *Remora*, for the computer or the user |
| `Remora.reg` | Windows: `reg import` or a deployment script | The example policy in `HKLM\SOFTWARE\Policies\Remora` |
| `policy.json` | Linux: copy to `/etc/remora/policy.json`, owned by root, mode `0644` | The example policy |
